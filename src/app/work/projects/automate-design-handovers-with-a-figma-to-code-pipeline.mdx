## Overview

The Digital Media Recommender is an intelligent platform designed to personalize the learning experience by recommending not just educational videos, but also engaging media content like games, web series, and movies that align with the user's chosen domain of interest. The system leverages smart recommendation logic to cater to diverse learning preferences, making education more relatable, immersive, and enjoyable.


## Key Features

- **Smart Recommendations**: Suggests multimedia content (videos, games, movies, series) based on the selected learning domain.

- **Category-Based Learning Paths**: Users can explore predefined or custom learning categories like Science, History, Coding, etc
- ** Gamified Suggestions**: Includes game-based learning suggestions to encourage interactive education
- **Entertainment with Education**: Recommends movies or shows that offer strong educational or conceptual relevance.


## Technologies Used

- **Frontend**: React.js (with modern component architecture and responsive design)

- **Backend**: Django REST Framework (for robust API development)

- **Database**: MongoDB (for storing user preferences, content data, and category mappings)

## Challenges and Learnings

🔄 Mapping Entertainment to Education: Associating games or movies with educational themes required thorough research and metadata analysis.

📊 Data Curation: Creating a balanced and diverse content dataset across domains was time-consuming.

⚙ Recommendation Logic: Building a meaningful recommendation engine that isn’t just keyword-based but also relevance-aware.

🌐 Integration: Ensuring seamless integration of the frontend with backend APIs and MongoDB.
