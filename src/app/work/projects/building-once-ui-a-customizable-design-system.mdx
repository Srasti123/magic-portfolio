## Overview

The Orrery Web App is a dynamic, browser-based visualization tool that simulates the orbits of planets and Near-Earth Objects (NEOs) in a solar system-like interface. Designed to make complex orbital mechanics and asteroid tracking accessible and engaging, the app allows users to observe real-time trajectories, learn orbital parameters, and understand how close NEOs come to Earth—all through an interactive 3D experience.


## Key Features

- ** Planetary and NEO Orbit Visualization**: Circular orbits for planets and elliptical orbits for NEOs, displayed with accuracy and clarity.
- **Interactive 3D UI**: Users can rotate, zoom, and explore the solar system using intuitive controls.

- **NEO Close Approach Info**: Displays key data like distance from Earth, orbital period, approach year, and return cycles.

- **Celestial Object Details**: Real-time display of object metadata, such as diameter, orbital speed, distance from the sun, and moons (for planets).
- **Educational Overlay**: Simplifies Keplerian elements and other orbital parameters for learners.



## Technologies Used

-3D Graphics: Three.js (WebGL-based rendering for realistic planetary motion)

-Data Source: NASA JPL Open APIs (for NEO and planetary data)

-Other Libraries:

-React Three Fiber (for integrating Three.js in React)

-D3.js (for orbit paths and smooth animations)

-Axios for API consumption

-GSAP / Framer Motion for animations


## Challenges and Learnings

🧮 Orbital Mechanics Simulation: Translating Keplerian elements into accurate 3D motion was complex and required deep mathematical understanding.

📊 Dynamic Data Handling: Parsing and visualizing live JSON data from NASA’s APIs in a performance-optimized manner.

🧭 Real-Time User Interaction: Implementing intuitive camera controls and object selection within a crowded 3D scene.

⚖ Performance Optimization: Rendering multiple moving bodies in real-time while maintaining FPS stability.
