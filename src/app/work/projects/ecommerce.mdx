## Overview

An e-commerce website built with Next.js, enriched by Clerk, and paired with an admin panel to manage operations effectively. This platform is designed to provide both customers and administrators with seamless, efficient, and secure features.


## Key Features

1. **User Authentication**: Clerk offers secure login options like MFA, SSO, and passwordless authentication.
2. **Dynamic Content**: Next.js ensures a personalized and fast user experience.
3. **Admin Panel**:
   - **Dashboard**: Comprehensive overview of sales, revenue, and analytics.
   - **Product Management**: Add, update, or remove product details and images.
   - **Inventory Control**: Track stock levels in real time.
   - **Order Management**: View, process, and update customer orders.
   - **User Management**: View customer profiles, purchase history, and engagement.
4. **Responsive Design**: Optimized for mobile, tablet, and desktop users, including the admin interface.
5. **Real-Time Updates**: Live sync for both the storefront and the admin panel.


## Technologies Used

- **Next.js**: For developing both the e-commerce website and the admin panel.
- **Clerk**: For user authentication across both user-facing and admin-facing sides.
- **Stripe**: For payment processing.
- **Sanity CMS**: For dynamic content management.
- **Tailwind CSS**: To create a responsive and modern design.
- **Zustand**: For seamless state management.
- **GraphQL**: To optimize data querying across the website and admin panel.

## Challenges and Learnings

1. **Role-Based Access**: Implementing secure access levels for the admin panel.
2. **Data Syncing**: Ensuring real-time updates between the website and admin panel.
3. **Admin UX**: Designing an intuitive interface for the admin panel.
4. **Scalability**: Supporting more users and administrative tasks as the business grows.
5. **Error Handling**: Managing potential conflicts like simultaneous inventory updates.

## Outcome

The website, now equipped with a powerful admin panel, offers:
- **Improved Operational Efficiency**: Simplifies order and inventory management.
- **Enhanced User Security**: Secure role-based access ensures data safety.
- **Business Insights**: Admins gain detailed analytics to make informed decisions.
- **Seamless Experience**: Real-time updates ensure the admin panel and website are always in sync.
